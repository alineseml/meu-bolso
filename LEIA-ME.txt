MEU BOLSO — VERSÃO 2

Esta versão mantém a mesma chave de armazenamento local da versão anterior e adiciona compras no cartão e estimativa de faturas. Como o código é atualizado no GitHub Pages, seus lançamentos existentes devem continuar no mesmo navegador/dispositivo, mas faça backup antes de substituir arquivos.

COMO ATUALIZAR:
1. No repositório GitHub, abra index.html.
2. Clique no lápis Edit ou substitua o arquivo usando Add file > Upload files.
3. Envie o novo index.html e confirme em Commit changes. Você também pode enviar todos os arquivos deste pacote.
4. Aguarde a atualização do GitHub Pages.
5. No iPhone, feche o app e abra novamente. Se aparecer a versão antiga, atualize a página no Safari. O cache offline pode demorar a atualizar; se necessário, abra o link no Safari primeiro.

NOVO:
- Adicionar compra no cartão com valor, data, cartão e número de parcelas.
- Calcular uma estimativa mensal da fatura com base no fechamento do cartão.
- Ver compras por cartão e excluir compras.
- A chave local existente é preservada para compatibilidade.

LIMITAÇÕES IMPORTANTES:
- A estimativa é simplificada e deve ser conferida com a fatura oficial.
- Ainda não controla pagamento da fatura, juros, estornos, taxas, múltiplas moedas ou regras especiais dos bancos.
- Os dados continuam locais no navegador, sem sincronização automática.
- Faça backup e use dados fictícios enquanto testa.
